# Proof-of-Concept Research

## Live conversational avatar options

### Short answer

Not really for HeyGen or D-ID, but a couple of competitors offer free live minutes. These are enough to record a demo, but not enough to support ongoing use by parents or investors.

### Provider options

- **HeyGen:** The free plan is for generating videos, not live chat. It provides 3 watermarked videos per month, each up to 1 minute. Live chat is a separate API product, and HeyGen does not provide free API credits.
- **D-ID:** The free option is a 14-day trial with 3 minutes.
- **Anam:** The free plan includes 30 minutes, one custom avatar, one simultaneous session, and a three-minute limit per conversation.
- **Tavus:** One roundup lists a free tier with 25 minutes of conversational video. The snippet is ambiguous about which vendor it describes, so availability should be verified on Tavus's site.
- **Simli:** This is only the face layer; the AI brain and voice must be supplied separately. One guide using Simli with ElevenLabs reports limited free minutes on Simli and 10,000 characters per month on ElevenLabs.

## Implications

The free minutes are sufficient to run a few real conversations and screen-record them. The recordings can be edited into a polished vision video containing dynamic answers.

The free limits are not sufficient to let parents or investors try the product themselves.

## Language validation

Hebrew and Arabic quality could not be confirmed for any of these providers. Before building around a platform, use a free trial to test at least one Hebrew question on each candidate.

If Hebrew voice quality is weak, the fallback is text chat with an avatar face.

## Recommended comparison test

Create a short test script of 3-4 questions in Hebrew, English, and Arabic and run it across the available free trials for a fair comparison.
